## The base

One machine: **declare what you'll stop distinguishing, then collapse.** A quotient is the laziest object honoring "what if these were equal?" — collapses exactly what you asked, nothing more. Every handle grips this move differently.

## The handles

**QUOTIENT** — Fire on: "What are we agreeing not to distinguish?" Every collapse is a declaration first; undeclared collapse is smuggling.

**KERNEL** — Fire on: "What did this map forget — and where's the ledger?" Every structure-respecting transformation discards a coordinate; discard isn't loss unless nobody filed it.

**COSET REPRESENTATIVE** — Fire on: "Which concrete stands for this line — and who chose it?" A class of equivalent options needs one named delegate; the delegate is a choice, not a right, and canonical picks are gifts of extra structure.

**NORMALITY** — Fire on: "Does this collapse survive every vantage — or only the one it was built from?" A collapse is real only if it commutes with every motion of the room; if run-order or vantage changes the lines, the lines are procedure-artifacts.

**LAGRANGE** — Fire on: "Does the partition close its headcount?" Cosets partition — nobody in two lines, nobody in none — and room = lines × line length; if the count doesn't close, the partition is fake.

**IDEAL** — Fire on: "Does this absorb whatever touches it?" Some elements swallow — compose an ideal with anything and you're in the ideal; absorption computes the blast radius, and collapsing by the right maximal absorber leaves a space invertible everywhere.

**FIRST ISO** — Fire on: "This map respects structure — so it's secretly a division. Name its kernel." Every structure-respecting map factors as forget-the-kernel, deliver-the-remainder-system; if you can't name what a functor forgets, you don't know the functor.

**HOLONOMY** — Fire on: "Go around the loop and come back: did it come back changed?" A loop that returns altered exposes hidden curvature. The leftover is the fight between the steps, fixed only up to where the loop starts; if every loop comes back clean, the local rules agree everywhere.

**GAUGE** — Fire on: "Is there a place to stand outside, or does every part carry its own frame?" With no global frame, each place picks its own delegate. Only what survives every local choice is real, and the rule for carrying between places is part of the structure.

## The loop — equipment mode

Type it → every map: kernel first → too much detail: pass to the quotient (declare aloud, work downstairs) → before trusting lines: normality → compute downstairs, lift upstairs, then well-definedness (an answer that changes when the delegate swaps was about the delegate, not the line) → contamination: find the ideal, quotient by it.
